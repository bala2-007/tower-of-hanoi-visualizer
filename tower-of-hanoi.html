Time and space complexity

Recurrence: to move n disks, move n−1 disks aside, move the largest disk, then move n−1 disks back on top. So T(n) = 2·T(n−1) + 1, with T(1) = 1.

Time: O(2n). Solving the recurrence gives exactly 2n − 1 moves, and no solution can use fewer. Each extra disk doubles the work: 3 disks take 7 moves, 8 disks take 255.

Space: O(n). The recursion goes n calls deep, so the call stack holds at most n frames. The three peg stacks together never hold more than n disks.

  • Paradigm: divide and conquer, with the problem shrinking from n to n−1 each call.
  • Data structure: each peg is a stack, because only the top disk can move (LIFO).
